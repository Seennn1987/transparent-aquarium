## 1. 目的

今の水槽は「生息地の雰囲気の中で泳ぐ」舞台で、暗い緑・霧・色仕上げの都合で、透明標本らしい光の通り方が出しにくい。  
いったん水槽は置き、**添付のような白いスタジオ＋リアルなガラス容器**の中で、イカの見た目とゆったりした動きを観察・調整できるようにする。

完成時の体験:

- ブラウザを開くと、白い背景にガラスの標本ケースが1本ある
- ケースの中に液があり、その中で透明標本イカがゆっくり動いている
- ケースを回して見たり、ズームしたりできる（観察が主。水槽のような広い泳ぎはしない）
- 色・透明度・ツヤなどを画面上のつまみで変えられる（調整用。本番向けの見た目を固める道具）

## 6. 体験の詳細仕様

### 6.1 画面

- 白い（ごく薄いグレー可）スタジオ背景
- 中央に縦長のガラス標本ケース（蓋つき）
- ケース内は透明な保存液（わずかに粘性がある印象の動き）
- イカは液の中央付近に浮き、壁・底・液面に触れない
- やわらかい影が床（または台）に落ちる程度

### 6.2 ガラス（リアルさの優先順）

1. 厚みのあるガラス（底・蓋・壁）
2. 光のハイライト（縦の筋・蓋の玉の反射）
3. 屈折（中のイカがわずかに歪んで見える）
4. 液面の境目
5. （余裕があれば）ごく弱い色付き・汚れゼロの清潔感

### 6.3 イカの見た目（リアルさの優先順）

1. 白い後ろ光で青緑が濃く出る（水槽より Blender 静止画に近い条件）
2. 胴を通して消化腺の緑・頭周りの黄が透ける
3. 薄い膜・腕の輪郭が自然（白く飛ばない）
4. ツヤは輪郭寄り・弱い
5. 画面つまみで明るさ・染まり・ツヤ・透けを調整可能

### 6.4 動き（リアルさの優先順）

1. ホバリングを**遅め**（液が重い感じ）
2. 体全体がゆっくり上下・微小回転（漂い）
3. 稀に向きが数度だけ変わる
4. 壁に近づきすぎたらゆっくり戻す（ぶつからない）
5. ジェット噴射・速い泳ぎは初期オフ（観察の邪魔になるため）

### 6.5 操作

| 操作 | 内容 |
|---|---|
| ドラッグ | ケース（またはカメラ）を水平に回して観察 |
| ホイール／ピンチ | ズーム |
| 一時停止 | 動きを止めて形を見る |
| 編集パネル | 明るさ・染まりの濃さ・ツヤ・透け・漂いの速さ など |

## 7. 「極限リアル」の上限（約束できること／できないこと）

| できること（この計画の範囲） | できないこと／別計画が必要 |
|---|---|

| 白い光の下で透明標本らしい色と透け | 水槽の暗い緑の中と同じ見た目のまま極限を出すこと |
| 液中らしいゆっくりした動きの観察 | 物理シミュレーション完全再現（本物の粘性流体） |
| つまみで見た目を追い込む | ブラウザで Blender Cycles と同等のボリューム計算を毎フレーム |

限界にぶつかった場合の次の段階（本計画の外）:

- Blender 本レンダの「見せ用カット」を別途用意する
- または WebGPU／より重いエンジンへの載せ替えを別計画にする

- `src/jar.js`: 液柱を屈折レンズ（透過・屈折率1.47）、壁は薄い半透明＋縁で灰色の輪郭、蓋は透過ガラス

  - **Step 3 への申し送り**: 半透明のイカは液の屈折に写らない。イカの材質を不透明寄り（または透過材質）にする設計が必要

### Step 3（2026-09-24）

- 申し送りの解決: イカの頂点を瓶の軸から横に1.3倍広げて、液の柱のレンズ効果を再現（視点に追従）
- 色の測定（白スタジオ・胴の範囲の平均の 赤÷緑）: 染まりの濃さ 1.0 で 0.46／0.8 で 0.51／**0.65 で 0.56（採用）**／0.45 で 0.64
- 描く順番: 液（透過）→ イカ（吸収10・ツヤ11）→ 液面の輪19 → ガラスの壁20
- 水槽側のファイルは無変更。`npm run check` / `npm test` 通過

### Step 4（2026-09-24）
