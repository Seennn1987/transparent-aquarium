## 2. 現状の整理（コード・履歴から確認）

- **強み**: 透明標本の見た目に大きく投資済み（瓶の屈折、染まり、内臓の動きなど。修正 R18 まで）。似た作品が少ない
- **土台**: `水槽/` は Chase Lean 氏の「Desktop Habitats」（MIT ライセンス）。Mac 壁紙アプリ（`水槽/wallpaper/Wallpaper.swift`）が付属しており、デスクトップ水槽はほぼ手元にある。商用利用は可、著作権表示の保持が条件
- **ボトルネック**: 標本1体に R1〜R18 の反復がかかった。このままでは種類を増やせない。描写は Opus 5.5 のみが担当するルールのため、作業量にも制約がある
- **既存資産**: 魚（Gerres erythrourus）の骨格生成スクリプト `blender/generate_gerres_erythrourus.py`
- **調整パネル**: 組織の濃さ・染まり・器官の動きを変える調整パネルがすでにある（ゲーム化で流用できる）

## 3. 多角的な論点

### 3.1 公開（技術）

- `水槽/` は静的ファイルのみ。Cloudflare Pages / GitHub Pages に無料で置ける
- 要確認: スマホで WebGL が重すぎないか（必要なら軽量設定）
- 要確認: 標本シーンを入口にするか

### 3.2 マネタイズの選択肢（安く試せる順）

1. **動画素材**: 4K ループ動画・環境映像を YouTube / BOOTH へ。追加開発ほぼなし
2. **Mac デスクトップ水槽**: 既存の壁紙アプリを標本版にし、BOOTH / Gumroad で販売（数百〜千円程度）。Mac App Store は審査・年会費があるため後回し
3. **Windows**: Wallpaper Engine は Web ページを壁紙にできるので移植は軽い。ワークショップでは直接販売できないため宣伝用
4. **Web 版**: 無料公開＋標本パックの有料解放・投げ銭
5. **教育・展示**: 科学館・学校向けライセンス、実物の透明標本作家・ショップとのコラボ。単価は高いが営業が必要
6. **ゲーム（Steam など）**: 作り込みが最も必要で、回収までが最も長い

### 3.3 標本を増やす仕組み（全案の前提）

- 瓶・液・光・染まりは共通化し、種類ごとに変えるのは「形の生成スクリプト」と「設定値ファイル」だけにする
- 1体あたりの作業時間を測る（事業として成り立つかの基準）

### 3.4 権利・リスク

- `画像サンプル収集/` はネット由来の画像。参考専用とし、公開物・配布物に含めない
- 「新世界『透明標本』」（冨田伊織氏）はブランド名。商標を確認し、作品名は別にする
- GitHub リポジトリ（`Seennn1987/transparent-aquarium`）の公開・非公開を公開前に確認
- 「標本＝死んだ生き物」という受け止め方があるため、科学・アートとしての見せ方で文言を統一する

## 4. 作品の軸: 「本物では作れない透明標本」

- 実物の透明標本には作家と市場がある。一方、**クジラ・ゾウ・恐竜など実物では不可能なものを瓶に入れる**のは 3D でしかできない価値で、話題にもなりやすい
- 作品名もこの方向で付けると商標の心配を避けやすい（例: 「ありえない標本室」のような方向）

### 標本追加の順番案

| 順 | 標本 | 役割 | 理由 |
|---|---|---|---|
| 2体目 | カメレオン | 仕組みの検証 | 骨格の資料が多く本物らしさを確かめやすい。骨＝赤・軟骨＝青の典型的な二重染色で、イカ（青のみ）にない要素＝染まりの共通化テストになる。かぶと状の頭・巻いた尾・枝をつかむ足など見せ場が多い |
| 3体目 | クジラ | 看板・話題 | 透明標本の実例がなく見た目は創作になるため、仕組みが固まってから作る。小さな瓶に巨大な生き物というギャップ自体が見せ場 |

## 6. ゲーム化案: 透明標本づくりシミュレーション

評価: **面白い。ゲーム化の本命候補。** ただし最初は小さな体験版から。

### 6.1 面白いと考える理由

- **一番の見せ場が最初からある**: 濁った体が透け、骨や軟骨が青や赤に浮かび上がる瞬間。洗浄ゲーム PowerWash Simulator の「汚れが落ちる気持ちよさ」に近く、短い動画でも伝わる
- **今の描写の仕組みをそのまま使える**: 遊んだ結果（染色時間、透明化の進み具合など）で既存の調整パネルの数値を動かせば、同じ描写がそのまま仕上がりの差になる
- **競合がほぼいない**: 工芸系シミュレーションは人気ジャンルだが、透明標本の題材は見当たらない。教育的価値もある
- **作品の軸とつながる**: 本物の標本で腕を上げると、最後に「本物では作れない標本」（クジラなど）が解放される流れにできる

### 6.2 ゲームの中身（実際の工程を元にした案）

- 実際の工程: 固定 → 水洗 → 軟骨の染色（青）→ 酵素で透明化 → 骨の染色（赤）→ グリセリンに置き換え → 瓶に封入（本来は数週間〜数か月）
- **プレイヤーが決めること**: 各工程の「時間」「濃さ」「見極めのタイミング」
- **失敗も見どころ**: 透明化しすぎて形が崩れる／染めすぎて真っ青／泡が入る
- **評価**: 仕上がりの透明度と色の鮮やかさ
- **時間の扱い**: 早送りするか、放置ゲームのように実時間で進めるかを選べる設計も可能

### 6.3 注意点

- **扱い方**: グロテスクな表現は避け、理科の実験・工芸の雰囲気に統一
- **薬品の描写**: ホルマリン・水酸化カリウムなど実在の危険な薬品は、手順書のように見せずゲーム上の表現にとどめる
- **作業量**: 本格的なゲームには成長要素・経済・メニュー・多数の標本が必要。副収入が目標なら、最初から Steam 規模は重すぎる
- **担当の制約**: 失敗した見た目（染めすぎ・崩れなど）は描写の編集にあたるため Opus 5.5 が担当。ゲームの進行・操作画面は他モデルでも可

## 7. 進め方の案

| 段階 | 期間の目安 | やること | 次に進む判断基準 |
|---|---|---|---|
| 0 | 1〜2週 | 作品名決定／権利整理／`水槽/` を Cloudflare Pages で公開（標本シーンを入口に）／スマホ確認／イカのループ動画投稿・支援リンク設置 | 動画の再生数・保存数、サイト訪問数、支援数（2〜4週間観察） |
| 1 | 2〜4週 | 標本を増やす仕組み＋カメレオン | 1体あたりの作業時間が目標以内か |
| 2 | — | 体験版「標本工房」（イカ1体・工程4つ: 固定 → 染色 → 透明化 → 封入・結果画面）を Web に追加し、プレイ動画を投稿 | 遊んだ人の反応・動画の伸び |
| 3 | 2〜4週 | Mac 壁紙版の販売／支援会員で月1体の新標本／クジラ | 売上・会員数 |
| 4 | それ以降 | 反応が良ければ正式なゲーム化（itch.io / Steam で有料、またはブラウザ無料＋支援会員） | Steam のウィッシュリスト登録数など |

考え方: ゲームを先に作り込むより、**眺めるだけで価値があるか**を先に確かめる方が損が小さい。ゲームはその上に乗せられる。
