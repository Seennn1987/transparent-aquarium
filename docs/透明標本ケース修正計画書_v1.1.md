## 1. 評価と原因（コードで確認済み）

| 指摘 | 今の作り | 原因 |
|---|---|---|
| 瓶の形が参考と違う | 真っすぐな円筒＋平たい蓋 | 断面が単純。参考の「厚い段付きの台座・肩・首・すり合わせ栓・玉のつまみ」がない |
| ガラスの透け具合 | 蓋が白く濁って見える。胴は薄い半透明の膜 | 蓋は背景を屈折させるだけで、背景が白一色なので白い塊に見える。胴は屈折させず、縁を灰色にする疑似表現 |
| 奥行きがない | 照明がほぼ均一、影は円い模様1枚、ピントは全面一様 | 画面の仕上げ（後処理）なし。床は照明を受けない一色塗り、光の向きが画面から読めない |
| 液が微妙 | 液の柱が背景を少し歪めるだけ | 光が液を通って床に集まる明るい模様（集光）がない。液面の明暗、液の柱の縁の暗い帯、背景の左右反転（円柱レンズの効果）がない |
| イカに生々しさがない | 色は単純な縦方向の変化、目は楕円体1個、内臓は均一色の楕円体 | 模様（色素胞）の仕組みがない。目に水晶体・染まった軟骨の輪がない。光の吸収だけで描いているので組織のうっすらした白濁がない。レンズ効果は頂点を横に伸ばす代用で、本当の屈折ではない |

### 参考画像から読み取った「本物らしさ」の要素

- **瓶（鳥）**: 胴は厚いガラスで、左右の縁に**暗い帯と明るい筋**が交互に出る。中の標本は縁に近いほど**横に圧縮・歪む**。台座は分厚く段がある。蓋もつまみも**無色透明**で、中に周りの景色が逆さに映る。ほんのり青灰色
- **液**: 液面の線がくっきり（上が明るく下が暗い）。液の柱の中は周りより**少し明るく冷たい色**
- **撮影**: 白背景だが、床と奥の壁で明るさが違う。瓶の後ろがわずかにぼける。床に柔らかい影と、液を通った光のにじみ
- **イカ（5枚）**: 染まった部分は**青（空色〜青緑）**で、厚い所・縁ほど濃い。胴の中央は明るい。**目は大きく、濃い青の三日月形の輪**（染まった眼の軟骨）または赤茶色（色素が残った例）。頭は黄色に透ける例もある。腕とエンペラに**細かい点の模様**がうっすら。エンペラの縁は薄く波打つ。胴の中心に**軟甲の細い線**。内臓は輪郭がぼやけた半透明

## 3. 修正内容

### 3.1 撮影環境と奥行き（光・影・ピント）

- **画面の仕上げの仕組みを入れる**（水槽と同じ共有部品 `shared/postprocessing.js` を読むだけで使う）
  - 明暗を正しく計算してから最後に画面の色へ直す（今は近似）。白飛びしにくい仕上げの色調
  - **ピントのぼけ**: 瓶の中のイカに合わせ、奥の壁と床の奥がわずかにぼける（強さは調整可）
  - ごく弱い周辺減光と、ハイライトのにじみ
- **照明**: 左斜め後ろに大きな柔らかい光（ソフトボックス）、右に弱い補助光、上から弱い光。ガラスの縦の筋と、胴の丸みの明暗が読めるようにする
- **床と背景**: 床は照明を受ける白い台（わずかにツヤ）。奥の壁は床より少し暗い。境目は柔らかく残す（完全に消さない）
- **影**: 瓶の足元の濃い接地影＋光と反対側へ伸びる薄い影＋**液を通った光が床に集まる明るいにじみ**（集光を模様として描く）
- **カメラ**: 商品撮影に近い望遠寄り（画角を狭くし、瓶を画面の縦いっぱいに）

### 3.2 瓶の形（鳥の標本の瓶を手本に Blender で作り直し）

- 分厚い段付きの台座 → 円筒の胴 → なだらかな肩 → 首 → すり合わせの栓付き蓋 → 首 → 玉のつまみ
- 壁の厚みは今より厚く（参考の縁の帯が出る厚さ）
- 液は肩の下まで
- 寸法は液の中でイカが動ける範囲を保つ（起動時の収まり確認は継続）

### 3.3 ガラスの透け（屈折シェーダー R-A）

- 手順: ①後ろの景色（背景・床）を画像に描く ②イカだけを別の画像に描く ③瓶を描くとき、光線を円柱の式で追ってイカの深さと後ろの景色の位置を求め、そこから色を拾う
- 出るようになるもの: 縁の暗い帯と明るい筋、縁に近いほど中身が横に圧縮される、瓶越しの背景が左右反転、底と台座の厚いガラスの像、蓋とつまみが無色透明で景色が逆さに映る
- 今のイカの「横に1.3倍広げる」代用はやめ、本物の屈折に置き換える
- ガラスはほんのり青灰色（厚い所ほど濃い）

### 3.4 液

- 液面の線: 上側が明るく、下側が暗い（液面の裏での全反射）
- 液の柱の中を周りより少し明るく、わずかに冷たい色に
- 床の集光（3.1）と組み合わせて「光が液を通っている」ことを見せる

### 3.5 イカの生々しさ

**色と濃淡（参考写真を数値で測って合わせる）**
- 参考写真5枚の胴・腕・頭・エンペラの色を測り、目標値を表にする（今の赤÷緑の目安 0.5〜0.65 を置き換える）
- 染まりを今の青緑から**空色寄り**へ（下の確認事項1）
- 背側を濃く・腹側と胴の中央を明るく。尾の先と縁は濃く。エンペラの縁と腕の先は白に近い水色

**組織の白濁（散乱）**
- 吸収だけでなく、厚い所がうっすら白く光を散らす層を足す（参考の「ミルク状の半透明」）
- 内臓は輪郭をぼかし、奥の物ほど霞む

**形の作り込み（Blender）**
- **目**: 眼球＋水晶体（玉）＋虹彩のふち＋**染まった眼の軟骨の三日月形の輪**。色は確認事項2
- エンペラの縁を薄く波打たせる
- 軟甲（背中の芯）を細い線として見えるように
- 内臓（消化腺など）を楕円体から、くびれ・凹凸のある形に
- 口周り・腕の付け根の細部

**模様（色素胞の名残）**
- 胴の背側・頭・腕の外側に、細かい点がうっすら残る模様。形に貼り付き、動いてもずれない
- 濃さは調整可（Step 5 の調整パネルで扱う）

**濡れたツヤ**
- 表面の細かいしわによるツヤの揺らぎ（輪郭寄り・弱く）

## 7. 検証方法

- 各段階で、同じ視点の撮影を参考画像と横並びにして記録（`docs/images/specimen-refs/` と比較画像）
- 色の数値: 参考写真のイカの各部位の色を測って目標表を作り、画面の同じ部位を測る
- 屈折の計算はテストで確認（中心の光線は曲がらない、縁で全反射、左右反転）
- 重さ: 画質ごとのコマ数を測る
- 水槽ページ: 従来どおり開けること（回帰）、`npm run check` / `npm test` 通過

## 8. できること／できないこと

| できること | できないこと |
|---|---|
| 参考の瓶に近い形・縁の帯・中身の歪み・無色透明の蓋 | 写真とピクセル単位で一致 |
| 奥行き（ピントのぼけ・照明・影・集光） | 本物の光線追跡による正確な集光 |
| イカの目・模様・濃淡・白濁の再現 | 1個体ごとの自然な個体差（手作業の造形が別途必要） |

限界が見えたら: Blender Cycles の本番画像を「正解」として並べ、差を数値で詰める。それでも届かない所は別計画にする。

### R2（2026-09-25）照明・床・影・集光
- メインの光を**左手前の上**に（最初は左奥に置いたが、影がカメラ側へ伸びて瓶の陰と画面下端に隠れたため変更）。影は瓶の右奥の床へ伸びる。左奥には縁を光らせるだけの弱い光
- `src/studio.js` の床を計算で描く方式に: ガラス瓶は普通の影を落とさないため、液の柱の淡い影（遠いほどぼけて薄く）＋中心の**液を通って集まった明るい筋**（ごく淡い水色）＋足元の接地影。床は屈折の元の像になるので不透明のまま。強さは `FLOOR_LOOK` で調整可（R7 の調整パネルで扱う）
- 背景幕: 光の当たる側を明るく、反対側を少し暗く。映り込みの部屋も同じ光の配置に合わせた（正面右の細長い縦の光の筋、左奥の縁の光）
- 丸い模様1枚だった接地影は廃止（床の計算に統合）
- カメラを少し引いて床を画面に入れた
- 重さ: 1コマ約14ミリ秒（2016×1134画素、通常画質）
