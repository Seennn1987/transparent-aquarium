## 1. 結論

1. **外形（体の膜・皮膚の形）は、CT ではなく、写真と図の外形と、文献の比率から作る。** 保存した標本の CT の外形は、変形・やせ・写りの欠けがあり、直すほど手間がかかった。最後にシュモクザメの胴が「流線的」になったのは、参考の図 3 枚の外形に合わせ、CT は断面の形の下書きにだけ使ったとき
2. **CT がよく効いたのは、硬い骨の形と、体の中の位置。** 頭骨・顎・歯・肩帯・ひれの骨の形、背骨の線と椎骨の境目、ひれの付け根の位置、体腔の位置。ここは写真では分からず、CT で一度で決まった
3. **CT に写らないものが多い。** 石灰化していない軟骨（エラの骨、肋骨、血道弓、尾びれの鰭条、カメレオンの胸骨や肋軟骨）、内臓の形、心臓は、解剖の図と文献から作った。透明標本で目立つ青い軟骨の多くは、この「CT に無いもの」だった
4. **色は CT からは決まらない。** 色は、染まった実物（透明標本・胚の二重染色）の写真の測定から決めた
5. したがって次の標本は、**外形 = 写真と図、位置と比率 = 文献と写真、骨の形 = CT（あれば）、軟骨と内臓 = 解剖図、色 = 染めた標本の写真、動き = 計測の論文**、と役割を分けて集めてから作る

## 2. 3 体で何を元にしたか

| | ヤリイカ | エボシカメレオン | シロシュモクザメ |
|---|---|---|---|
| 形の元 | 写真の比率（眼の幅 ≈ 頭幅の 0.35 など） | 全身 CT（MorphoSource、骨 72 本）。頭骨は最初 CT 無しで写真から推測 | 全身 CT（Kamminga et al. 2017、CC0、3.3 GB） |
| 外形（膜） | 写真から作った形 | CT の軟部 → 「ボロボロ」「ゾンビ」→ 骨ごとの断面の表で作り直し | CT の軟部 → 幅を倍率で広げる → 参考の図の外形に合わせ直す（4 回） |
| 軟骨 | 写真と解剖の文 | CT に写らず、場所を出典で表にして作った | エラの骨・肋骨・鰭条・血道弓を図と文献から作った |
| 内臓 | 形を写真と解剖から | 体腔の褐色の一塊 | CT の体腔からの取り出し（案 1）は内臓に見えず、図（BIODIDAC）の並びを CT の位置に置いた（案 2c） |
| 色 | 参考写真の通し光を測った | 透明標本の写真を原寸で測り直した | 胚の二重染色（Eames et al. 2007）の写真を測った |
| 動き | 休んだヤリイカの数値 | 呼吸の動きを見る向きで決め直した | 近い種の計測（Webb & Keyes 1982、Hoffmann & Porter 2019 ほか） |

## 3. データの種類ごとの評価

| データ | 強いこと | 弱いこと・手間 | 次の使い方 |
|---|---|---|---|
| 全身 CT（保存標本） | 骨の 3D の形（頭骨・顎・歯・肩帯）、背骨の線と椎骨の数、ひれ・体腔の位置。全長に対するひれの位置は文献の範囲に入った（第 1 背びれ 0.28、第 2 背びれ 0.63） | 保存の変形（横倒し、尾の伸び、頭の横向き、首の倒れ、胸郭のつぶれ）。軟部はやせて点々にしか写らない（カメレオンは体の内側の 62% が 0）。軟骨・内臓・心臓は写らない。容量と中間ファイルが大きく、作り直せるようにする手間がかかった（シュモクザメの CT 処理のスクリプトは 71 本、うち A3「変形を戻す」の段だけで 22 本） | 骨の形と体の中の位置だけに使う。外形の正にしない |
| 横・背中・腹からの図と写真（生きた・新しい個体） | 外形（背と腹の線、上から見た幅の変わり方）。全体の印象（流線形、首の細さ） | 絵描きによる違い（Raver と FMIB 45527 で背の線の高さが違う）。写真は斜め・死んだ個体・小さい画像が多い。目で読んだ数は粗い（読んだ点を結ぶと波になった） | 外形の正にする。2 枚以上を全長でそろえて重ね、なめらかな線にしてから使う |
| 文献の計測（全長比の表） | ひれの位置、頭の幅、尾びれの長さ。数で確かめられる | 胴の高さ・幅の数は見つからないことが多い。個体差の範囲が広い | 位置と比率の確かめに使う。外形の数が無い所は図で補う |
| 解剖の図（BIODIDAC、解剖書） | CT に写らない軟骨・内臓・心臓の形と並び | ライセンス（CC BY-NC など）。種が違う（ツノザメ類） | 作る部品の形の元。位置は CT の体腔・骨に合わせる。どの図から作ったかは計画書に書く |
| 染めた標本の写真（透明標本、胚） | 色（骨の赤紫、軟骨の青、膜の濁り） | 同じ種の写真が無いことが多い。ライセンス未確認の図がある | 色の正。原寸で測り直してから数を使う |
| 動きの計測の論文 | 尾の振りの回数・振れ・波長・旋回の半径 | 同じ種の論文が無い（シュモクザメは近い種で代用） | 数の出典の表を作り、無い数は案を見せて決める |

## 4. CT について: 当初の考えと実態

当初の考え（カメレオンの頭骨のあと、手順書 第 3 節）: 「その種の 3D データ（CT の STL など）があるなら、形はそれを正にする」。正面の形を写真の推測で外した経験から、CT を正にすれば形が決まると考えた。

実態:

1. **骨は CT で決まった。** 頭骨・顎・歯・肩帯は、写真では作れない立体が一度で出た。シュモクザメの全長に対するひれの位置も文献と合った
2. **外形は CT で決まらなかった。** 保存標本は変形していて、CT の外形を「正」にすると、変形も一緒に写した
   - カメレオン: 体の表面が点々で「ボロボロ」「動かしたらゾンビ」、胸郭が横から押され「肋骨が潰れて内臓が入る場所がない」
   - シュモクザメ: 横倒し・尾・頭の向き・首の倒れを 20 段以上で戻した。そのあとも胴の膜は、写真に合わせて幅を 1.55 倍に広げて丸くなり、「胴体の形状が違う」「ボコボコと波打っている」と言われた
   - 調べると、CT の胴は幅 0.06・高さ 0.10（全長比）で、参考の図（幅 約 0.10、高さ 約 0.12）より細かった（保存でやせたとみられる）。背骨から遠い腹は、ひれの肉を外す処理で削られ（半径 77 → 55 mm）、切り口が約 57 mm おきに波打っていた
3. **透明標本で見せたい青い軟骨の多くが CT に無かった。** エラの骨、肋骨、血道弓、尾びれの鰭条、カメレオンの胸骨や肋軟骨は、図と文献から作った
4. **CT の処理そのものに時間を使った。** 中間ファイルの置き場、作る処理の欠け、作り直しの確かめ（3.4）に 1 段を使った。役に立ったが、外形のためには不要な手間だった

まとめ: CT は「骨と位置の正」としては要る。「外形の正」としては要らない（むしろ外形を CT から作ると直しが増える）。CT が無い種でも、外形と色と比率は作れる（ヤリイカ）。骨の立体が見どころの種（頭骨が複雑な種）だけ、CT を探す価値がある。

## 5. うまくいった要因

| 要因 | 例 |
|---|---|
| 外形を参考の図の外形に、数で合わせた | シュモクザメの胴: FMIB 51331（上から）と Raver・FMIB 45527（横から）の外形を、ブラウザで画素を列ごとに読み、全長比の線にして合わせた。そのあと「流線的」に近づいた |
| 外形の線そのものをならしてから使った | 断面の上下の端を、背は 40 mm・腹は 90 mm でならした線にそろえた（案 2、決定）。参考の点を結んだだけの線は波を作った |
| 断面をなめらかな閉じた曲線で当てた | 中央値で切る処理をやめ、左右対称の 7 項で当て、外へ膨らんだ形で包んだ。腹の帯とくびれの筋が消えた |
| 決める前に、案を並べてブラウザで切り替えた | 「画像じゃ分からないので、ブラウザで３つを切り替えて」から、`?pick=` の欄で glb と色の案を切り替える形が定着した |
| 実際の標本ページで撮って、同じ向きで並べた | 撮る道具（shoot-hammerhead.mjs）で 3 方向を撮り、いま・前の版・案を 1 枚にした |
| 膜を不透明にして光を当てた診断用の絵を作った | 透けた絵では見えにくい凹凸（首の段、面の継ぎ目の筋、木目の段々、くびれ）が、一目で見つかった。凹凸の大きさを数でも測った |
| 作り直しを別のフォルダで行い、元と比べた | `rebuild/` に複製して作り、`compare_glb.py` で頂点まで一致を確かめてから既定にした。`work/` は上書きしていない |
| 動きの数を出典の表にした | 尾の振り 1.25 Hz、片側 0.09 L、波長 0.91 L、旋回の半径 0.374 L。決めた値だけを使った |

## 6. うまくいかなかった要因（プロデューサーの指摘から）

| 指摘 | 起きていたこと | 次からの扱い |
|---|---|---|
| カメレオン「全然違う」（頭骨の正面） | 正面・上・下の写真が無いまま、側面から立体を推測した | 3 方向の外形の参考を、作る前にそろえる |
| カメレオン「ボロボロ」「動かしたらゾンビ」 | CT の軟部の点々をそのまま膜にし、面を外した跡が穴になった | 膜は CT から作らない。骨を包む断面の表、または参考の外形から作る |
| カメレオン「肋骨が潰れて内臓が入る場所がない」 | 保存標本の胸郭のつぶれを正しい形とみた | CT の形も変形しているとみて、別の個体・写真と比べる |
| カメレオン・シュモクザメ「意味がわからない」「口頭で言われてもわからない」 | 段の記号と数字だけで尋ねた | 案ごとの絵を並べた 1 枚を見せ、決めると次に何が起きるかを言葉で書く |
| シュモクザメ「あまり透明標本ぽく見えません…背骨も円状の何かが繋がっているように見えて」 | CT に写るのは椎体の外の石灰化した殻だけで、輪の並ぶ管に見えた | 写りの悪い部品は、CT の位置と太さを使って形を作り直す（椎骨は部品から作った） |
| 「胸の骨がないことが気になりました」「エラボネの大きさが小さい、位置も頭側に寄っている」 | 写りの弱い骨を捨て、置き場所を推定で決めた | 捨てる前に部位ごとの色分けの図で見る。置き場所は CT の空気（エラのふくろ）などの手がかりで決める |
| 「胴体の形状が違う」「背鰭のあたりの胴が一番膨らんでいる」 | 胴の幅を 1 つの比（頭の幅 ÷ 胴の幅 = 2.6）で決め、頭を 33% にしたあとも胴を直さなかった | 外形は 1 つの比でなく、全長に沿った線（幅・高さ）で参考と合わせる。決めた比を変えたら、関係する部位を測り直す |
| 「胴の形状がまだ違います…あなた自身で調査し」 | いただいた写真を目で読んだ幅（0.13）に合わせ、幅が高さを超える、文献と逆の形にした（文献は左右に平たい） | 参考は自分で集め、2 枚以上で確かめる。断面の縦横（高さと幅）を文献で確かめる |
| 「胴の表面に不自然な凹凸」「波打ったり」 | 処理（中央値で切る、首の切り替え、面の格子、ひれの継ぎ目）が作った凹凸を、透けた絵だけで見ていて気づかなかった | 不透明の診断用の絵と、凹凸の数の測定を、形の段の出口に入れる |
| 「真横から…まだまだボコボコ」「いきなりモデルを直すのではなく、どこまで直すべきか図で示して」 | 参考の点を結んだ目標の線そのものが波打っていた。直す前に範囲を見せずに作っていた | 目標の線はならしてから使う。直す前に、波の場所と動かす量の図で承認をもらう |
| 「推定と書く必要はありません」（2026-10-14）、「こんなこと求めたことはありません」（2026-10-17、この文書の「作った部品には『推定』と書く」に対して） | 10-14 にそう言われたのに、前の担当が CLAUDE.md に書いた「部品名と計画書に『推定』と書く」を守り、心臓・肋骨・鰭条の部品名に「推定」を付け続け、この文書でも決まりとして書いた | 決まりの文書（CLAUDE.md など）とプロデューサーの言葉が食い違うときは、プロデューサーの言葉を正にし、決まりの文書を直す。CLAUDE.md と書き出しの部品名から消した |
| 「日本語で」（3 回）「必ず日本語で回答するようにルール化して」 | 会話の要約から再開した直後などに英語で返した | 全体の CLAUDE.md の冒頭に決まりとして書いた |
| 「瓶の高さが変わっていません」（「2倍、高さも2倍」を取り違え） | 器の形を変えずにサメを縮め、高さが変わったと説明した | 言葉の指示は、目で見て分かる結果（器の高さ）で確かめてから「済み」と言う |

## 7. 次の標本の進め方（元データの集め方）

手順 0（生物カード）の前に、次を表にする。表の欄は「何の役に使うか・出典・ライセンス・向き・解像度」。

1. **外形の参考を 3 方向（横・背中・腹）、それぞれ 2 枚以上**。生きた個体か新しい個体の図・写真。パブリックドメインか CC を優先する。外形は画素を列ごとに読み、全長で割った線にする
2. **文献の計測の表**（全長比のひれの位置、頭の幅、胴の高さと幅があれば）。断面が縦長か横長かも文献で確かめる
3. **骨の 3D データ（CT）は、骨の形が見どころの種だけ探す**。使うのは骨と位置。軟骨と軟部がどこまで写るかを、最初に断面で確かめる（写らない部品の一覧を先に作る）
4. **解剖の図**（軟骨、内臓、心臓）。CT に写らない部品の形の元
5. **染めた標本の写真**（色の正）。原寸で測る
6. **動きの計測の論文**（同じ種か近い種）

作るときの順:

1. 外形の線（横の背と腹、上の幅）を参考から作り、ならす。これを先に決めてもらう
2. 骨を置く（CT があれば CT から。無ければ図から）。骨が外形の内側に入るかを数で確かめる
3. 膜は外形の線に合わせて作る（断面の形はなめらかな曲線。CT は断面の下書きにだけ使う）
4. 毎段の出口: 実際のページで撮った同じ向きの並べ、不透明の診断用の絵、凹凸の数、骨のはみ出し、面の向きと開いた辺
