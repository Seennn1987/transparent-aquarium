## 2. 生物カード（文献から書ける部分。2026-10-17）

### 2.1 3 秒の見せ場（候補）

- 平たい円盤の傘と、頭の上の耳のような 2 枚のひれ
- 傘の縁まで透けて見える 8 本の腕と、吸盤と触毛の列
- 体の中の 1 本の弓形の殻（ひれの支え）、大きな眼、顎板の琥珀色

### 2.2 部品の残り方（仮。色は第 3 節の決定のあとに確定）

| 部品 | 生きているとき | 透明標本で |
|---|---|---|
| 皮膚・筋肉・腕・傘の膜 | 茜色〜チョコレート色の色素。ゼラチン質 | 溶ける（透明になる）。地の染まりはイカの膜と同じ扱いにするかを第 3 節で決める |
| 殻（ひれの支え）とひれの軸の軟骨 | 軟骨のような質 | 染まる（青の候補。強さは未確認） |
| 頭の軟骨・眼の軟骨 | 無い | 作らない |
| 顎板 | キチン、褐色 | 色素が残る（琥珀。イカの顎板と同じ） |
| 歯舌 | 無いか退化 | 作らない |
| 平衡石 | 炭酸カルシウム | 染まる（赤の候補。大きさは未確認） |
| 眼 | 大きい。角膜が無い | 水晶体は溶ける。網膜の杯と色素はイカのカードに合わせる |
| 吸盤 | 1 列 | 溶ける（輪郭だけ残る）。雄なら肥大吸盤 |
| 触毛 | 吸盤と交互に 2 列 | 溶ける（細い突起の輪郭） |
| 鰓 | 短い腎臓形、鰓葉 6 枚 | 透けて見える内臓 |
| 心臓・鰓心臓 | 体心臓 1、鰓心臓 2 | 内臓の時計で動かす |
| 消化管 | 胃・盲嚢・腸・中腸腺 2 葉 | 褐色の内容物が残る（イカの消化腺と同じ扱いの候補） |
| 墨汁嚢 | 無い | 作らない |

### 2.3 比率（文献の mm から。画像の px の測定はまだ）

| 比 | 値 | 元 |
|---|---|---|
| 胴の幅 ÷ 全体の径 | 23 / 55 = 0.42 | Ijima & Ikeda 1895 本文 |
| ひれを含む横幅 ÷ 全体の径 | 65 / 55 = 1.18 | 同上 |
| 眼球の径 ÷ 眼の所の頭の幅 | 9 / 26 = 0.35 | 同上 |
| 傘の深さ（口から、平均）÷ 全体の径 | 約 25 / 55 = 0.45 | 同上 |
| 体の高さ ÷ 全幅 | 28 / 150 = 0.19、25 / 150 = 0.17 | Taki 1963（*O. japonica*） |

原記載の個体は若い雄（径 55 mm）、Taki の個体は成熟した雄（全幅 150 mm）で、大きさが約 3 倍違う。どちらを正にするかは第 3 節で決める。画像を落としたあと、原記載の図版（3 図とも原寸）を px で測り、本文の mm と合うかを確かめる。

### 2.4 通し光

未測定。タコの透明標本の写真が無いので、借りる標本を決めてから（第 3 節）。

### 2.5 動き（候補）

- 器の中で浮き、傘をゆっくり開き閉じし、そのあいだにひれが 2〜3 回打つ（Bizikov 2004 の比）
- 使わない動き: 速い泳ぎ、膜の裏返し、風船のようにふくらむ反応
- 内臓: 体心臓と鰓心臓（イカの `organ-motion.js` の型）。回数は低温の値が原典で確かめられていないので、案を見せて決める

## 3. 決めてもらうこと（参考がそろってから、案の絵を並べて聞く）

| 問い | なぜ要るか | 見せる案 |
|---|---|---|
| 大きさと性別（若い個体の径 55 mm か、成熟した雄の全幅 150 mm か） | 雄の肥大吸盤、傘の深さ、ひれの比が変わる | 原記載の図と、成熟した雄の図（Meyer 1906・Sasaki 1929）を並べる |
| 姿勢（平たく広がる、浅い漏斗、傘を下ろしたパラシュート形） | 外形の線と器が変わる | 生体写真の 3 つの姿勢を並べる |
| 器（イカの瓶の断面のまま倍率だけ変えるか、シュモクザメのような低い器か） | 手順書 第 4 節の決まりを変えるかどうか | 2 つの器に同じ輪郭を入れた絵 |
| 色をどの標本から借りるか（ヤリイカで測った染まり、ほかの透明標本の写真） | 実物のタコの透明標本の写真が無い | 借りる候補ごとに、同じ輪郭を塗った絵 |
| 殻の形（横向きの棒、浅い弓形、U 字） | 文献が食い違う | 図版を落としたあと、文献ごとの図を並べる |
