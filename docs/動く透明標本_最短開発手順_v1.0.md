## 1. 最短の型

ヤリイカに時間がかかったのは、瓶・光・屈折・組織の描き方・内臓の時計がまだ無く、さらに眼と頭を「生きている形」のまま何度も作り直したためである。舞台は R1〜R4、R7、R18 の瓶側で既にある。

次の1体は、次の順だけ進める。

1. 形を作る前に、1枚の生物カードを書く（残る組織・写真の比率・色の測定・瓶の中の動き）
2. Blender で輪郭の静止画を、測った比率と揃える
3. 瓶に入る遅い動きを1つだけ作り、Blender の動画で判断する
4. 既存の標本ページに glb を載せる。瓶・屈折・スタジオは触らない
5. 測った色に染まりを合わせる
6. 透けて見える部品を、1つずつ「標本に残る形」で足す
7. 既にあるつまみで生々しさを足し、画面が濁ったら戻す
8. 内臓の時計を足す。動きは画面で1画素より大きく

各段の出口を満たすまで次へ進まない。出口を飛ばすと、ヤリイカの眼（R8〜R15）と同じやり直しになる。

## 3. 失敗要因

遠回りになった順に書く。次の生き物では、右の列を着手前の確認にする。

| 起きたこと | なぜ遠回りになったか | 次からの扱い |
|---|---|---|
| 水槽用の材質と暗い舞台のまま透けを出そうとした | 背後光と霧の数値が、白い透過光と別物だった | 標本ページの光と材質を使う。水槽の数値はコピーしない |
| 均一な照明・楕円体の内臓・横 1.3 倍のレンズ代用のまま、色の数値だけ動かした | 原因が仕組みの不足だった | 参考と並べて「形が無い／光が無い／屈折が無い」のどれかを先に名指しする。名指しできない項目のつまみは触らない |
| 生きている眼（水晶体の玉、カメラに向けた閉じた輪）を標本として置いた | 透明標本では水晶体は溶け、両目が正面の輪には見えない | 生物カードの「溶ける／染まる／色素が残る」を書いてからメッシュを作る |
| 三日月を網膜だと思って作り直した | 顔の三日月は軟骨の弧だった。網膜は杯 | 部品の名前と、標本での残り方を1文にしてから作る |
| 頭を細くし、眼を出し、また広い頭に戻した | 写真の比率が無い状態で、指摘のたびに反対側へ振れた | 比率を3〜5個測ってから大きさを決める。パネルのスライダーは、その比率の周辺だけ動かす |
| 調整が glTF の p.y を左右として扱った | 左右は p.z。目の大きさを動かすと眼が背中側へずれ、上下で割れた | 新しい骨やスライダーを足すとき、左右・背腹・前後の軸を1行で書いてから接続する |
| 頭と腕、嘴・墨袋・軟甲に水槽用の色が残った | 金色の切れ目、黒い三角、黒い軸が写真と違った | 隣接部位の色をまたいで測る。黒い部品は、参考で黒いかを測ってから吸収を上げる |
| 左右対称で染まりが一様な、きれいな模型になった | 形が合ったあとも標本に見えなかった | 形の出口のあとで、まだら・左右差・内容物を足す。種は固定する |
| 傾いて沈んだ姿勢にした | 「浮いて内臓が動く」というコンセプトと逆だった。R17 で浮遊に戻した | 瓶の中の姿勢は、生物カードに書いたコンセプトと一致させる。死んだ沈みはコンセプトに書いたときだけ |
| 擦れ傷・黄ばみ・縁の光・ガラスの緑を最初から強くした | 瓶が灰色、傷が縞、漏斗が白い台形、底が緑の塊になった | 効果は画面で分かる最小から上げる。濁ったらその効果だけ戻す |
| ガラスの蓋が白い塊に見えた | 背景が白一色で、屈折した先も白だった。スタジオの映り込みが無かった | 瓶は既存の屈折を使う。新しい透明部品を足すときも、白い背景の映り込みを同時に入れる |
| 腕の付け根が白く点滅した | 半透明の頭の中の濃さ 0 の頂点と、細い三角形の外への色の外挿。浅い角度の反射では NaN がぼけて広がった | 濃さ 0 の面は描かない。組織の値は三角形の内側で取る。吸収の下限は 0。反射の累乗は範囲を制限する |
| 確認用の別作業が同じ見た目ファイルを同時に編集した | R18 の瓶側が、ギャラリー化の完了待ちになった | 1体の見た目の編集中は、瓶・材質・glb を触る作業を重ねない |
| 他のタブを開いたまま描画時間を測った | 絶対値がばらつき、効果の有無と区別できなかった | 重さは、その効果を 0 にしたときとの差で測る |
| 2体目の glb を、イカの全部位が無いと読めない検査に通そうとする | `specimen-material.js` は外套・腕などイカの部位が揃っていることを要求する。カメレオンにはその部位が無い | 手順 3 で、検査する名前を開いた glb の部位にする。吸収の式、瓶の屈折、スタジオは組み替えない。描画一式の汎用化は、瓶に載ったあと、違った項目だけ |
| 2体目を、イカの瓶の現寸に押し込めようとした | 動物の比率が瓶の内径に負けた。廃棄した横向き骨格のあとの計画も、収める側を逆にしていた | 動物はカードの比率のまま作る。瓶は断面を変えず、一様な倍率だけ動物に合わせる |
| 2体目の計画書の比率を、書いた担当の測定のまま正とした | カメレオンの比（眼窩 0.29、吻端〜腰 2.75 など）は、書かれた画像と画素で再現できなかった。「縦900」は頭全体の高さで、輪の寸法ではなかった | 比率は、手順 1 の担当が正の写真の原寸で測り直してから使う。表には「どの画像の、どこからどこまで、何 px」を書き、誰でも再現できるようにする |

| カメレオンの呼吸を、肋骨が背骨の軸まわりに左右へ開く動きだけで作った | 開く向きがカメラの奥行きと同じで、側面からは動いて見えなかった | 動きは、見る向きで動くかを先に確かめる。側面の標本なら、肋骨が前へ起きて腹が深くなる成分を入れる |
| Blender の材質を、ノードの英語名（`Principled BSDF`）で探した | 日本語表示の Blender ではノード名が訳され、見つからずに止まった | ノードは名前でなく種類（`BSDF_PRINCIPLED` など）で探す。新しいスクリプトは、ユーザーの Blender でも一度通す |
| 骨を、太さが一定の細い管で組んだ | 比率は合っても「針金の檻」に見え、標本の質感にならなかった（カメレオン頭骨） | 骨は実物の輪郭どおりの板と帯で作り、重ねて Voxel Remesh で一つの殻に融合してからならす。開いている所だけ穴にする。参考と同じ角度の並べ画像で毎回比べる |
| 指摘の 4 点だけを直し、ほかの見え方を確かめずに渡した（カメレオン頭骨 第 2 版） | 正面の幅を絞りすぎて紙のように薄くなり、第 1 版より悪く見えた | 1 回直すたびに、参考写真・前の版・今の版を同じ向き（側面・斜め前・斜め下・正面・下）で 1 枚に並べ、自分で見比べてから渡す。前の版より悪くなった向きがあれば、その変更を戻す |

| 通し光の表を、以前の版の数のまま使いかけた（カメレオン 第5節） | 測り直すと、肋骨（0.70/0.60/0.51 → 0.65/0.25/0.49）と指（0.92 → 0.35〜0.45）が再現しなかった | 色の数も比率と同じく、正の写真の原寸で測り直してから使う。点に印を付けた画像で、狙った部位に当たっているかを見る |

写真を表面に貼る案、瓶の中で水槽と同じ広い泳ぎをする案、ブラウザで全光線追跡する案は、計画の時点で棄却済みである。次の生き物でも採用しない。

## 5. 開発手順

描写（形・色・光・瓶・glb の再書き出し）は Opus 5.5 が行う。手順の確認、テスト、瓶を触らない読み込みは他の担当でもよい。

各手順の終わりに、出口の文を満たした記録を残してから次へ進む。

### 手順 0 — 生物カード

コードもメッシュも作らない。次を1枚に書く。

- 3秒で気づく見せ場（カメレオンなら、かぶとの頭・巻いた尾・枝をつかむ足、骨の赤と軟骨の青）
- 生きているときの部品一覧と、透明標本でどうなるか。各部品を「溶ける／染まる／色素が残る」のどれか1つに置く
- 参考写真から測った比率を3〜5個（頭に対する眼、胴の長さに対する尾、など）
- 参考写真の通し光を4〜6部位（厚い所、薄い膜、骨、軟骨）。白い光の写真で、背景で割った赤/緑/青
- 瓶の中の姿勢（浮く、向き、壁との空き）と、使わない動き（速い泳ぎ、瓶の外に出る動作）
- 動かす内臓と、休んでいる個体の回数。画面上の振れ幅の見込み
- 元データの表（`標本づくりの元データと手法_振り返り_v1.0.md` 第 7 節、2026-10-17）: 部位ごとに「何を元に作るか」を決める。外形は横・背中・腹の図か写真を各 2 枚以上、位置と比率は文献の計測、骨の形は CT（あれば）、軟骨と内臓は解剖の図、色は染めた標本の写真、動きは計測の論文。CT があるときは、断面を見て「写らない部品」（石灰化していない軟骨、内臓）の一覧も書く

出口: カードの「残る形」と矛盾する部品案が、リストに残っていない。元データの表の外形の欄が埋まっている（外形を CT だけから作る計画になっていない）。

### 手順 1 — 輪郭の静止画

Blender で白い光の静止画を1枚出す。ブラウザには出さない。輪郭はカードの姿勢で、カードの比率の大きさで作る。イカの瓶の現寸に合わせて動物を縮めない。

出口: カードの比率と、輪郭の静止画が一致する。一致しない項目はメッシュを直す。色と内臓には進まない。

確かめ方: 同じスクリプトで、正の写真と同じ姿勢の骨格も出す。頭骨の長さと吻端をそろえて写真に重ね、頭・背骨の弧・腰・尾が重なることを見る。瓶の姿勢では、弧長の比と頭の比だけを比べる。

### 手順 2 — 瓶に入る動きを1つ

骨を自動生成し、その場の遅いループを1つ作る。ヤリイカではホバリング（エンペラの波、腕の揺れ、呼吸の太さ）がそれにあたる。判断は Blender の動画で行う。

出口: その動物に見える。液の中の空きに収まる。速い移動クリップは、この段階では作らない。

確かめ方: 静止時と動きの山のフレームを色違いで重ね、動く部位が見る向きで動いているかを見る。ループ中の外接の広がりを測り、手順 3 の瓶の空きに使う。

### 手順 3 — 既存の瓶に載せる

標本用 glb を書き出し、標本ページの読み込み先をそのファイルにする。ヤリイカは外套長 0.72、空き 0.12 で、当時の瓶に合わせた。2体目以降は動物をその寸法に縮めない。瓶は `generate_specimen_jar.py` の断面のまま、一様な倍率だけ変えて、壁・液面・底から空き 0.12 を残す。屈折の式とスタジオとギャラリーの並びは変えない。半径を 0.62 で固定している画面側は、書き出した瓶の寸法を読む。

出口: 瓶の中に浮かび、既存の屈折越しに輪郭が歪む。水槽ページの glb は以前のファイルのまま。`npm test` が通る。

### 手順 4 — 染まり

組織の計算は `specimen-material.js` を使う。変えるのは種の色だけ。骨が赤・軟骨が青の種は、イカの空色変換をそのまま使わず、カードの通し光に合わせた染まりを足す。画面の同じ部位を測る。

出口: 測った4〜6部位が、カードの目標の範囲に入る。新しいメッシュは足していない。

### 手順 5 — 透ける部品を1つずつ

カードの見せ場だけを足す。1部品ごとに、次を終えてから次の部品へ進む。

1. 「標本に残る形」を1文で書く
2. その形だけ作る
3. 同じ視点で見て、比率を測る
4. 隣の組織と色が切れないことを、境界をまたぐ明るさで確認する

眼のような入れ子は、開口の向きをカメラに向けない。左右の軸を接続する前に、左右・背腹・前後を1行で書く。

出口: カードに書いた見せ場が、その1文どおりに見える。

### 手順 6 — 生々しさ

既にあるつまみから入る。まだら、染み、輪郭のにじみ、左右の寸法差、内容物、液の霞。崩しの乱数は固定する。

強さは、画面で分かるとこから上げる。瓶全体の色が濁った、傷が縞になった、縁が白い図形になった、のいずれかになったら、そのつまみだけ戻す。

出口: 左右が同じ模型に見えない。瓶の液体が灰色の塊になっていない。

### 手順 7 — 内臓の時計

`organ-motion.js` の型に、カードの回数を載せる。骨のループ（呼吸など）と拍を一致させる。一時停止で全部止まる。強さ 0 でその内臓だけ止まる。

振れが画面で 1 px 未満なら、回数ではなく変形の形を大きくする。

出口: 自動テスト（間隔、一時停止で不変、強さ 0 で停止）が通る。静止画と画素を比べ、カードに書いた内臓がすべて動く。

### 手順 8 — その種だけの光学

手順 3〜7 のあと、参考にまだ足りない項目を1つ名指しする。名指しできない追加はしない。足すときは、その値を 0 にした画面と画素で差を見る。差が飽和（真っ白、真っ黒、瓶全体の変色）したら下げる。

出口: 名指しした項目だけが画面を変え、瓶の既存の屈折テストが以前と同じ結果になる。

## 6. 着手前の確認

次の生き物の作業を始めるとき、この一覧を上から見る。

1. 生物カードがある。溶ける組織を、生きている形のまま置く部品が無い
2. 比率と通し光の数値がカードにある。色の作業は、その測定のあとである
3. 瓶・`jar-optics.js`・スタジオを変更する作業が、同じ期間に入っていない
4. 水槽の glb と標本の glb が別ファイルである
5. 動きは瓶の中の浮遊と、カードに書いた内臓だけである
6. 新しいスライダーは、左右・背腹・前後の軸を書いてから接続する
7. 描写の編集は Opus 5.5 が行う
8. 読み込み検査が、その glb に無いイカの部位を要求していない
9. 外形の参考（横・背中・腹、各 2 枚以上）がそろっている。CT は骨の形と位置にだけ使い、外形の正にしていない（振り返り 第 1・4 節）
10. 段の出口に、実際のページで撮った同じ向きの並べに加えて、膜を不透明にした診断用の絵と、凹凸の大きさの数がある（振り返り 第 5 節）
11. 参考の点を結んだ目標の線は、ならしてから使う。直す前に、直す場所と動かす量の図で承認をもらう（振り返り 第 6 節）

## 7. 2体目で最初に違うところ

アイデアメモの候補はカメレオンである。手順 0〜3 と 5〜8 は上のまま使う。手順 4 だけ、ヤリイカに無かった作業になる。

- イカの染まりは青（軟骨と筋肉が同じ空色の系統）である。カメレオンの典型的な二重染色は、骨が赤、軟骨が青である
- 赤を足す場所は、カードで「骨」と書いた部品だけにする。瓶のガラスの緑や、液の黄ばみと混ぜない
- 見せ場は、かぶと状の頭、巻いた尾、枝をつかむ足。全身の内臓をイカと同じ密度で最初から作らない
- 生物カードと参考画像は `docs/カメレオン透明標本_計画書_v1.0.md` と `docs/references/chameleon/`。種はエボシカメレオン。姿勢は頭を下に浮かす。瓶はイカの断面のまま、大きさだけこの動物に合わせる
- 赤を `SKY_WEIGHTS`（イカの空色）に通さない。骨の部位だけに赤の吸収を足す
- 1体にかかった日数を、手順 0 の開始日から手順 7 の出口までで記録する。アイデアメモの段階 1 は、この時間が次の体でも使えるかを判断基準にしている

3体目（クジラなど、実物の透明標本が無いもの）は、手順 0 の「参考写真の測定」が創作の仕様になる。測定の代わりに、カードへ「どの実在の標本の染まりを借りるか」を書いてから手順 1 に入る。

| ギャラリー | 他の標本と並べる。ただし実寸の比のままだと器がイカの瓶より大きくなりすぎるので、並べたときの大きさは調整する | — |

変えないもの: 白いスタジオ、ガラスの材質（緑、厚み）、液（グリセリン）の屈折率と色、組織の吸収の計算、調整パネル、確認スニペットの型。

新しく作るもの: 器の形（蓋なし）、液面が上に開いていることの光学（上から見たときの液面の屈折と映り込み）、回遊の軌道と体のうねり、ギャラリーでの大きさの調整。

この例外を、次の生き物の既定にはしない。次の生き物では、第 1〜7 節の決まりから始め、例外が要るときはプロデューサーの決定をこの節に足す。

### 8.1 4体目（メンダコ）の例外（2026-10-17、プロデューサー決定）

計画書: `docs/メンダコ透明標本_計画書_v1.0.md` 第 3.2 節。案の絵 `docs/mendako/step0_options.jpg` を見て、プロデューサー「姿勢は B、器は B、殻は上から B・後ろから C にします。色は A（イカと同じ空色）にします。」

| これまでの決まり | メンダコで変えること | 理由 |
|---|---|---|
| 瓶はイカの断面のまま、一様な倍率だけ変える（第4節） | シロシュモクザメと同じ蓋のない低い器 | 平たい体（高さ ÷ 横幅 0.44）は縦長の瓶では上下が空く。上から傘とひれの形が見える |

変えないもの: 動き（器の中の浮遊と内臓。シュモクザメのような回遊はしない）、白いスタジオ、ガラスの材質、液、組織の吸収の計算（色はイカと同じ空色）。
