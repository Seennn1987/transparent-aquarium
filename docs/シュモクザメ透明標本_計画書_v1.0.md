## 1. CT で分かっていること（2026-10-13 に確かめた）

ZMA.PISC.108725 の DICOM を開いて確かめた値:

| 項目 | 値 |
|---|---|
| 断面 | 2093 枚 |
| 画素 | 512 × 512、0.735 mm |
| 断面の厚み | 0.5 mm（体軸の方向に約 1046 mm の範囲） |
| 撮影 | TOSHIBA Aquilion、100 kV、再構成 FC03、PatientPosition FFS（DICOM ヘッダ） |

最大値の投影（`~/transparent-aquarium/シュモクザメ/_確認/全体/Sphyrna_zygaena_シロシュモクザメ_ZMA.PISC.108725.png`、左が背側から、右が横から）で見えたもの:

- 頭の翼の軟骨。左右の端に眼のくぼみ
- 頭蓋、あご（歯の列が見える）
- 椎骨が 1 個ずつ。体はほぼ真っすぐ
- 胸びれ・背びれの軟骨、体の外形

確かめたこと・見えた問題:

- 骨格の濃さ（300 以上）は、断面の左右・上下の縁に届いていない。頭の翼は画面の中に収まっている
- 尾の側の端の 3 枚にある濃さ 300 以上の 452 ボクセルは、撮影台（トレイ）だった（手順 0 の記録）。尾びれの上葉は撮影範囲の端まで達していて、先がわずかに切れている可能性がある
- 標本を載せたトレイが一緒に写っている。外す
- 画素 0.735 mm は、カメレオン（0.104 mm）より粗い。体長に対する細かさは、体軸の方向ではカメレオン（約 750 ボクセル）より細かい（約 2090 断面）。ひれの条（角質鰭条）、歯の形、皮歯（うろこ）は写らないと見込む。手順 0 で確かめる
- ウチワシュモクザメ ZMA.PISC.108685 の投影（`docs/hammerhead_ct/`）は、前の版の確認用として残す

## 2. カメレオンから持ち込むもの

### 2.1 うまくいったので、そのまま使う

| うまくいったこと | カメレオンでの記録 | サメでの使い方 |
|---|---|---|
| 形を CT から取った | 手作りの頭骨は「クオリティが低すぎる」「正面が全然違う」と言われた。CT に変えて解決 | 最初から全身 CT を形の正にする。手作りの骨は作らない |
| CT を骨ごとに分ける道具 | 分水嶺、背骨の軸、椎骨ごとの分割（`ct_body_pipeline/` の seg.py、axis5.py、vert3/4.py） | 椎骨の列、頭（頭の翼を含む）、あご、鰓弓、ひれごとに分ける |
| 保存の変形を測って戻した | 胸郭の横ずれと寝る角を、別の個体（Digimorph）と写真 06 で比べて戻した | 頭の翼の左右差を同種の頭部 CT と、体を他の 12 体と比べて戻す |
| 膜を「断面の太さの表」から作った | CT の表面のままでは「ボロボロ」「動かしたらゾンビ」。表から展示の姿勢で一枚に作り、閉じた殻にした（skinloft2.py） | 体の外形も同じ方法で作る。サメは外形が CT にはっきり写るので、表は作りやすいと見込む |
| 光の通り道を足し合わせる描き方 | 閉じた殻の裏と表の深さの差で厚みを取り、組織ごとに吸収を掛けた（`chameleon-material.js`） | 同じ計算を使う。組織の名前と色の数だけ変える |
| 写真から色を解いた | 写真の画素を色で分け、組織ごとの吸光度を最小二乗で解いた（fit_stain01.py）。色の型を 2 つ持てるようにした（`?stain=06` / `01`） | 実物の写真が見つかったら同じ方法で解く。色の型は複数持てる作りのまま |
| 写真の関節の点に姿勢を合わせた | 前肢・後肢の向きを、写真 01 の肘・手首・指先に合うように解いた（forefit.py、fit_fore.py） | ひれの開き、体の曲がり、頭の向きを、写真の点に合わせて解く |
| 瓶を画面ごと縮めずに倍率で入れた | 動物の箱から瓶の倍率 J を出し、画面は今のまま動物を 1/J で描いた（`jarEnlargement`） | 同じ関数を使う |
| 開き方を URL で分けた | `?specimen=chameleon` を付けなければイカのまま | `?specimen=hammerhead` を足す。イカとカメレオンは変えない |
| 瓶なしのライトボックスで先に判断した | `chameleon.html`（瓶なし）で色と形を決めてから瓶に入れた | `hammerhead.html` を同じ作りで作る |

### 2.2 失敗したので、着手前に避ける

| カメレオンで起きたこと | サメで先に打つ手 |
|---|---|
| CT の断面を 4 枚に 1 枚に間引いたら、細い肋骨が途切れた | 間引かない。0.5 mm の断面のまま使う（512 × 512 × 2093 は約 1.1 GB。メモリが足りなければ、間引かずに頭・胴・尾の範囲に分けて扱う） |
| もう 1 体の個体の骨（指の骨 4 本）が舌骨に混ざっていた | 最初にトレイと、体から離れた塊を外す。外したものを画像で残して確かめる |
| 膜の面を外したら穴になり「ボロボロ」 | 面は外さない。体積のうちに切り離してから閉じた殻にする |
| 主な骨を重みの和や、いちばん近い骨で決めて面が伸びた | 主な骨は体積で切り離したときの持ち主にする。面を減らしてから重みを付ける |
| 保存標本の CT をそのまま正しい形とみた（胸郭が潰れていた） | 椎骨ごとの断面で左右の対称を測り、同属の全身 CT と比べる。違えば測った値で戻す |
| 写真の骨を取り違えた（前腕を上腕、下腿を大腿と測った） | 写真の点を取る前に、その骨の名前を CT の骨格と重ねた絵で確かめる |
| 姿勢の角の符号を確かめずに使った（上腕があごの方へ向いた） | 角は、写真で測った値と向きを表に書いてから使う |
| 呼吸を、見る向きでは動かない方向に付けた | 動きを付けたら、止めた所と動きの山を色違いで重ねて、見る向きで動くか確かめる |
| 計画書の比率を、書いた担当の測定のまま使った | 比率と色は、手順 0 の担当が原寸で測り直す。「どの画像の、どこからどこまで、何 px」を書く |
| 1 点だけ色を合わせたら全体が暗くなった | 骨の画素の色の分布（中央値）で合わせる |
| 4 点だけ直して、ほかの向きが悪くなった（頭骨 第 2 版） | 直すたびに、参考・前の版・今の版を同じ 5 方向で 1 枚に並べ、自分で見比べてから渡す |
| 選択肢を言葉と数字だけで尋ねて「意味がわからない」と言われた | 決めてもらうときは、模式図と実際の画像を並べた 1 枚の絵で見せる |
| Blender のノードを英語の名前で探して、日本語表示で止まった | ノードは種類で探す。新しいスクリプトは Mac の Blender 5.2.2 で一度通す |
| three.js の Vector4 の既定の w = 1 で、内臓の通り道に全部が足された | 係数のベクトルは全成分を書く |
| 出典の無い部品を作りかけた（のどの軟骨） | 出典か写真で確かめられない部品は作らない |

### 2.3 プロデューサーの指摘から決まっている方針

| 指摘・決定（カメレオン） | サメでの扱い |
|---|---|
| 形を本物に寄せるのが最優先。骨の表面のざらつきは後回し | 形の出口を満たすまで、質感に進まない |
| 形を作るときは、常に参考の骨格画像と見比べる | 毎回の静止画に、同じ向きの CT の投影と参考写真を並べる |
| 横に伸ばして瓶の外に置いた骨格は不可 | 最初から展示の姿勢で作る |
| 動物を今の瓶に押し込めない。瓶の大きさを動物に合わせる | 動物は縮めない。器の形は手順書 第 8 節の例外で「蓋のない低い円柱」に変えた（2026-10-13）。並べたときの大きさは画面の上だけで縮める |
| 「肋骨が潰れて内臓が入る場所がない」 | 体腔の深さを同属の全身 CT と比べ、潰れていれば戻す |
| 「なんで体の表面がボロボロ」「ゾンビみたい」 | 膜は表から作り、閉じた殻にする（2.2） |
| 「肩の関節の位置が変」「丸で囲った骨の位置がおかしい」 | 肩帯・腰帯とひれの付け根の位置を写真の点で解く |
| 順番は 透明標本の完成 → 動かす → 瓶に入れる（2026-10-13） | この計画も A → B → C の順にする |
| 色の型を増やすときは、今のものを残す（写真 01 の版） | 色の型は追加で持つ。上書きしない |

## 3. まだ分からないこと（手順 0 で確かめる）

推測で埋めない。出典か画像で確かめてから表に書く。

| 問い | なぜ要るか | 確かめ方の候補 |
|---|---|---|
| サメの透明標本はどう染まるか。全身が軟骨なので青が主か。椎体・顎・歯・皮歯は赤く染まるか | 色の設計の土台。骨が赤のカメレオンと逆になる可能性がある | 板鰓類の透明標本の写真を探す（Adam Summers の透明標本写真など）。魚の透明標本の染色の文献（Song & Parenti 1995 など、第 7 節）。候補で、まだ読んでいない |
| シュモクザメの実物の透明標本の写真はあるか | 無ければ、手順書 第7節の「3体目」と同じく、どの標本の染まりを借りるかをカードに書く | 博物館・研究室の画像、学会の図。ライセンスを確かめる |
| 頭の翼の左右差・反りは変形か | 戻すかどうかが決まる | 同種の頭部 CT（RMNH.PISC.4206）と左右の角・反りを比べる |
| 頭の細部（あご、鼻の溝、眼の位置）が 0.735 mm で足りるか | 足りなければ細部の参考が要る | 同種の頭部 CT（RMNH.PISC.4206、画素 0.588 mm）と比べる。近縁のヒラシュモクザメの軟骨頭蓋（Nova Southeastern 大学、CC BY 4.0）は形の参考として見る |
| 生きた姿勢と、保存で曲がった姿勢の差 | 展示の姿勢を決める | 生きたシロシュモクザメの写真（上・横）で、体の曲がりと頭の向きを測る |
| 安静時の鰓の動き（呼吸）と心拍の回数 | 内臓の時計 | シュモクザメ類か近いメジロザメ類の文献を 1 件ずつ。見つからなければ、カメレオンと同じく近い種の値を仮にし、プロデューサーの了承をとる。イカの 0.75 Hz・毎分 50 拍、トカゲの値は使わない |
| 内臓（肝臓・胃・腸）が CT に写っているか | 透ける見せ場になるか | 体腔の断面を見る。サメの肝臓は大きいという一般知識は、出典で確かめてから使う |

## 4. 計画（A 透明標本 → B 動かす → C 器に入れる）

各段の出口を満たすまで次へ進まない。出口の判断はプロデューサー。各段の記録は、この文書に日付つきで足す。新しく分かった成功・失敗は、同じ作業の中で手順書にも戻す（`.cursor/rules/specimen-procedure.mdc`）。

### 手順 0 — 生物カード（コードもメッシュも作らない）

1. 第 3 節の問いを調べ、出典つきで答えを書く
2. 3 秒の見せ場を決める。候補: 横に長い頭の翼、椎骨の列、放射状のひれの軟骨
3. 部品ごとに「溶ける／染まる（何色）／色素が残る」を 1 つ置く。軟骨が主なので、カメレオンの「骨は赤」をコピーしない
4. 比率を 3〜5 個測る（例: 頭の翼の幅 ÷ 全長、頭の翼の幅 ÷ 体の幅、尾びれの上葉 ÷ 全長）。全身 CT・同種の頭部 CT・写真で測り、どの画像の、どこからどこまで、何 px かを書く
5. 色の目標（通し光）を 4〜6 部位。実物の透明標本の写真が無いときは、借りる標本と理由を書く
6. 展示の姿勢を決める（下の「決めること」）

出口: カードの「残る形」と矛盾する部品案が無い。比率と色に出典がある。

**決めたこと: 器と姿勢**（2026-10-13）

縦長の瓶に入れる 4 案（`docs/hammerhead_ct/pose_options.png`）を見たうえで、プロデューサーが「蓋のない低い円柱の器の中を回遊する」に決めた。背が常に上を向くので、どこから見ても頭の翼の形が分かる。

### A 透明標本（静止、瓶なし）

| 段 | 中身 | 出口 |
|---|---|---|
| A1 CT の掃除 | トレイと離れた塊を外す。外したものの画像を残す | 体だけの体積がある |
| A2 骨格を分ける | 頭（頭の翼・頭蓋）、あご、鰓弓、椎骨（1 個ずつ）、肩帯・腰帯、ひれ（胸・腹・背・臀・尾） | 部品ごとの画像で、取り違え・混ざりが無い |
| A3 変形を戻す | 頭の翼の左右差・反りを同種の頭部 CT と、体の曲がりと断面を同属の全身 CT と比べて測る。体の横倒し（頭は背が上、首から胴の前で右へ 40〜60°、胴の中ほど〜尾柄で 65〜87°、尾びれで約 30° 倒れている）を起こす（第 9 節）。戻すかはプロデューサーに図で見せて決める | 測った数と、戻した前と後の図がある |
| A4 輪郭の静止画 | 白い光の静止画。展示の姿勢と、写真と同じ姿勢の 2 つを出す | カードの比率と一致する。写真と同じ姿勢で重なる |
| A5 体の膜 | 断面の太さの表から、展示の姿勢で閉じた殻にする | 開いた辺 0。骨が膜の外に出ない |
| A6 染まり | `hammerhead.html`（瓶なし）で、カードの色に合わせる | 測った部位が目標の範囲に入る |
| A7 透ける部品 | カードの見せ場だけを 1 つずつ。眼、内臓など | 1 文どおりに見える |
| A8 生々しさ | 既にあるつまみ（まだら、左右差、内容物）。乱数の種は固定 | 左右が同じ模型に見えない |

A の出口: 瓶なしの静止画を、参考写真と同じ向きで並べる。プロデューサーが「透明標本に見える」と判断する。

### B 動かす（器なし）

器の中を回る泳ぎを 1 つ作る。速い突進、口を開けて食べる動き、器の外へ出る動きは作らない。透明標本が泳ぐこと自体が「現実にはあり得ない」創作なので、速さは液（グリセリン）の中らしくゆっくりにする。

| 段 | 中身 | 出口 |
|---|---|---|
| B1 骨組み | 椎骨の列（1 個ずつ）、頭、あご、鰓弓、ひれの骨を作る。左右・背腹・前後の軸を 1 行書いてから接続する | うねらせても膜が裂けない。骨が膜から出ない |
| B2 泳ぎの型を測る | 生きたシロシュモクザメ（無ければシュモクザメ類）の泳ぎの数を出典つきで決める: 尾の振れの周期と振れ幅、体を波が伝わる速さ、回るときの曲がりの半径、頭の翼の左右の傾き | 数と出典が表にある。見つからない数は、プロデューサーに図で見せて仮の値を決める |

#### 頭のすぐ後ろの出っ張り（2026-10-15、A5 からの残り）
